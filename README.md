# PPB Simple AI

Aplikasi ini menggunakan unsupervised clustering untuk menggabungkan
titik-titik Wi-Fi yang berdekatan menjadi 1 titik representatif. Demi
menghasilkan peta koneksi wifi yang lebih rapi dan bersih.
